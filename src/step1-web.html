Get your ChatGPT export

ChatGPT's official data export is the only way to get your full history out. It's free on every plan.

  1. In ChatGPT, open Settings → Data controls → Export data, then confirm.
  2. OpenAI emails you a download link, usually within minutes (sometimes up to a day). The link expires after about 24 hours.
  3. Download the .zip and drop it here. No need to unzip it.
Why not just sign in? The ChatGPT/OpenAI API can't read your ChatGPT chat history; it only runs new requests. So the export file is the reliable route, and it means you never hand over a password or API key.
