    Import into Claude

    Unzip the kit first. Each folder under claude-projects/ (or the single claude-project-… folder) is one Claude project.

    1. Create a project in Claude

      At claude.ai/projects, choose New project and give it the folder's group name.

    2. Paste the instructions

      Open PROJECT_INSTRUCTIONS.md, copy the text under the line, and paste it into the project's instructions. It tells Claude to treat the imported chats as your history and cite them.

    3. Upload the chats

      Add chats-part-*.md (or the chats/ files) and INDEX.md to the project's files. Repeat steps 1–3 for each folder.

    4. Bring your ChatGPT memory too

      Chat history and memory are different things. Claude has a built-in memory import for your preferences and personal context: claude.com/import-memory.

    5. Optional: search everything with MCP

      For Claude Desktop or Claude Code, the mcp-server/ folder gives Claude search and read tools over the whole archive. Install once with npm install in that folder, then:

      claude mcp add chatgpt-archive -- node /FULL/PATH/TO/mcp-server/server.js

      For Claude Desktop, see mcp-server/README.md for the config snippet.

    6. Test it

      In your new project, ask: "What were the main things I worked on in these chats? List them with dates."

    FAQ

    Is my data sent anywhere?

    No. Your export is unzipped and converted inside this tab, and the kit is built locally. The only exception is the optional ✨ Claude buttons, which send the chat titles and first messages of one group to Claude to write a name and summary.

    Can I keep chatting in an old conversation?

    Not literally; ChatGPT threads can't become Claude threads. Start a new chat in the project and say what you want to continue. Claude can read the imported history and pick up from it.

    What's left out?

    Hidden system messages, abandoned edit branches, ChatGPT's internal reasoning and raw tool output. Images and uploaded files show as [Image] placeholders; re-upload any files you still need straight into the Claude project. Canvas documents and code are kept.

    My history is huge. Will it fit?

    Upload only what you still need: exclude old one-off chats in step 2. For everything else, the MCP server lets Claude search the full archive without loading it all at once.
